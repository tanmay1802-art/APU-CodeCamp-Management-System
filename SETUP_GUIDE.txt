================================================================
 APU CODECAMP MANAGEMENT SYSTEM
 SETUP GUIDE - READ THIS FIRST
================================================================

STEP 1: SET UP THE DATABASE
-----------------------------
1. Open SQL Server Management Studio (SSMS)
2. Connect to your SQL Server (use .\SQLEXPRESS or (localdb)\MSSQLLocalDB)
3. Open the file: CodeCamp_Database.sql
4. Press F5 to run it
5. You should see: "CodeCampDB created successfully with all tables and seed data."

TEST LOGIN ACCOUNTS (from seed data):
  Admin    : username=admin      password=admin123
  Trainer  : username=trainer1   password=trainer123
  Lecturer : username=lecturer1  password=lecturer123
  Student  : username=student1   password=student123


STEP 2: CREATE VISUAL STUDIO PROJECT
--------------------------------------
1. Open Visual Studio 2019 or 2022
2. Click "Create a new project"
3. Select "Windows Forms App (.NET Framework)"
   - NOT .NET Core / .NET 5/6/7 - use .NET Framework
4. Name it: CodeCampSystem
5. Click Create


STEP 3: ADD ALL .CS FILES
---------------------------
1. In Solution Explorer, right-click the project name
2. Add > Existing Item
3. Add ALL these files:
   - DatabaseHelper.cs
   - Models.cs
   - SessionManager.cs
   - LoginForm.cs
   - AdminDashboard.cs
   - TrainerDashboard.cs
   - LecturerDashboard.cs
   - StudentDashboard.cs

   NOTE: Visual Studio generates Form1.cs by default - you can delete it.


STEP 4: CREATE FORMS IN DESIGNER
----------------------------------
You need to create the GUI for each form in the Designer.
Here is what controls to add for each form:

--- LoginForm ---
  - Label:   "APU CodeCamp Management System" (title)
  - Label:   "Username"
  - TextBox: txtUsername
  - Label:   "Password"
  - TextBox: txtPassword  (set PasswordChar = *)
  - Button:  btnLogin     (Text = "Login")
  - Label:   lblError     (ForeColor = Red, Visible = False)
  Wire up: btnLogin.Click -> btnLogin_Click
           txtPassword.KeyPress -> txtPassword_KeyPress

--- AdminDashboard ---

STEP 5: UPDATE CONNECTION STRING
----------------------------------
Open DatabaseHelper.cs
Find this line:
  @"Server=.\SQLEXPRESS;Database=CodeCampDB;Integrated Security=True;"

Change Server= to match your setup:
  - SQL Server Express : .\SQLEXPRESS
  - LocalDB           : (localdb)\MSSQLLocalDB
  - Named instance    : COMPUTERNAME\INSTANCENAME


STEP 6: SET STARTUP FORM
--------------------------
1. Open Program.cs
2. Change Application.Run(new Form1()) to:
   Application.Run(new LoginForm());


STEP 7: BUILD AND RUN
-----------------------
Press F5 to build and run.
Log in with: admin / admin123
